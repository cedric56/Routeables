# Reshapes.Maui.Community

CommunityToolkit.Maui popups and snackbars for the modals, content and task dialogs and notifications of [`Routeables.Maui`](https://www.nuget.org/packages/Routeables.Maui).

```csharp
builder.UseRouteablesCommunityToolkit();   // instead of UseRouteables(); do not also call UseMauiCommunityToolkit()
```

See the [Reshapes overview](https://github.com/cedric56/Routeables/blob/master/Reshapes/README.md).
