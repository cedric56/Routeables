Search elements by role, name, value, or text content

Usage: agent-desktop-win32-x64.exe find [OPTIONS]

Options:
      --app <APP>                      Filter to application by name
  -v, --verbose                        Enable debug logging to stderr
      --debug                          Visual debug for snapshot/click; requires --screenshot PATH.html
      --window-id <window-id>          Scope to a single window ID (from list-windows)
      --role <ROLE>                    Match by accessibility role (button, textfield, checkbox ...)
      --screenshot <PATH.html>         Write a sensitive, local HTML screenshot visualization (new file only)
      --name <NAME>                    Match by accessible name or label
      --session <SESSION>              Select the snapshot namespace; session-owned refs require the same scope
      --agent-id <AGENT_ID>            Harness subagent ID within --session (1-64 letters/digits/-/_; or AGENT_DESKTOP_AGENT_ID)
      --value <VALUE>                  Match by current value
      --text <TEXT>                    Match by text in name, value, title, or description
      --trace <TRACE>                  Append reliability trace JSONL to this path
      --description <DESCRIPTION>      Match by accessible description
      --trace-strict                   Fail on trace setup/pre-action write errors
      --headed                         Prefer physical delivery for natural input commands and permit focus/cursor side effects. Default is strict headless semantic delivery.
      --native-id <NATIVE_ID>          Match by native automation id (AXIdentifier)
      --exact                          Require exact (case-insensitive) name/description/value matches
  -w, --wait-for <WAIT_FOR>            Poll until an element matching the role:text selector appears, then return the snapshot (snapshot and ref actions only)
      --root <ROOT>                    Search only inside this ref's subtree, not the whole window
      --wait-for-gone <WAIT_FOR_GONE>  Poll until no element matches the role:text selector, then return the snapshot (snapshot and ref actions only)
      --surface <SURFACE>              Surface to search (menubar, menu, sheet ...) instead of the window [default: window] [possible values: window, focused, menu, menubar, sheet, popover, alert, desktop, taskbar, system-tray, quick-settings, notification-center, toolbar, dock, spotlight, menu-bar-extras, system-tray-overflow, start-menu, action-center]
      --wait-timeout <WAIT_TIMEOUT>    Maximum wait time in milliseconds for --wait-for / --wait-for-gone (default: 30000)
      --state <TOKEN[=BOOL]>           Filter by state token (repeatable); append =true or =false
      --timeout-ms <MS>                Traversal deadline in milliseconds (default 5000; raise for a large tree such as a shell file dialog)
      --count                          Return match count only
      --first                          Return first match only
      --last                           Return last match only
      --nth <NTH>                      Return Nth match (0-indexed)
      --limit <LIMIT>                  Return at most N matches; defaults to 50 when omitted, use 0 for all
  -h, --help                           Print help
