# Reshapes.Razor.MudBlazor

MudBlazor dialogs, content and task dialogs, snackbar notifications and a MudBlazor layout for [`Routeables.Razor`](https://www.nuget.org/packages/Routeables.Razor).

```csharp
services.UseRouteablesServer<MainViewModel>(r => r.AddGeneratedRoutes());
services.UseMudBlazor();   // after UseRouteables; no need for UseRouteablesServices
```

See the [Reshapes overview](https://github.com/cedric56/Routeables/blob/master/Reshapes/README.md).
